## Overview

This repository contains a comprehensive research report on common network security threats, including DoS/DDoS, Man-in-the-Middle (MITM), IP Spoofing, and DNS Poisoning/Spoofing.

## Deliverable

- [network_security_threats_report.md](network_security_threats_report.md) — Full structured report meeting all checklist requirements:
  - Introduction
  - Detailed sections for each threat (explanation, real-world example, impact, 3+ mitigations)
  - Comparison table
  - Conclusion with 3 key takeaways
  - References (credible sources including NIST, CISA, MITRE ATT&CK)

## Why This Matters

Understanding these foundational network threats is essential for any security analyst. The report emphasizes practical mitigations and real-world context suitable for both technical teams and management briefings.

## Ethics & Scope

This is a pure research deliverable. No scanning or offensive testing was performed.
